## Changelog

**Skills pre-approve only the shell commands they run.** The `allowed-tools` of `/para-archive`, `/para-deep-clean`, `/para-new`, `/para-pipeline`, `/para-triage`, `/para-upgrade`, `/para-activity-review`, `/para-audit`, `/para-ingest`, `/property-dealsheet`, `/property-reconcile` and `/property-underwrite` list one pattern per command their steps run (`Bash(git mv *)`) in place of bare `Bash` and `PowerShell`, so any other command asks first. Reaction: re-sync the installed copies of those skills.

## What changes for you

While a skill runs it no longer approves every command by itself: anything outside the few it needs, such as pushing to a remote or deleting a file outright, asks you first.
