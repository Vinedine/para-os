## Changelog

- In a vault with a `## Who writes this vault` roster, add a Role column after Person, asking the operator for each row whether that person is the keeper, a member or a steward: CLAUDE.md

## Also new

- **Roles on a shared vault's roster.** Each person who writes a shared vault is now its keeper, a member or a steward, and triage reads which one is you from a small file instead of asking each time.

## What to do

- If you share a vault with someone: create `operator.json` in your para-os folder holding your own contact card's file name, such as `{"card": "jane-doe"}`.
- If you run several vaults: the `kind` field in your vault registry is no longer read, and you can delete it.
