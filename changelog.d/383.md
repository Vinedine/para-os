## Changelog

**Python 3.9 or later is required, and no skill runs by hand.** `para-shared/scripts.md` stops a skill where Python, its script or the shared library is missing, or the script exits 2, naming what failed; the references that restated a scan's rules as a by-hand procedure keep only what a step reads from the scan, and every scan's exit-2 message says what to install instead of pointing at a procedure. Reaction: before re-copying anything, check for Python 3.9 or later (`py -3 --version` on Windows, `python3 --version` elsewhere) and stop where it is missing, naming https://www.python.org/downloads/; then re-sync every installed `para-*` skill and `para-shared/` as trees, `/para-activity-review` and `/para-audit` included where installed.

## What changes for you

Python is now required. The skills no longer carry a slower by-hand path for a machine without it, so each one is shorter and reads less on every run.

## Do you need to do anything?

Install Python 3 from python.org if `/para-upgrade` says it is missing, then run it again.
