## Changelog

**The shared library is three modules, one per concern.** `para-shared/scripts/paraos_vault.py` keeps what reads a vault; `paraos_clone.py` reads the para-os clone a vault is measured against (the clone session, `clone_read`, `clone_files`, `addon_root`, `master_template`, `changelog_entries`, `entries_between`); `paraos_mail.py` reads mail threads, the notes they become and the ledgers that track them (`ingest_logs`, `ingest_ledger`, `watermark`, `unanswered`, `thread_hash`, `note_name_parts`, `written_under`). The `ingest-logs` command of `paraos_vault.py` is gone; `/para-triage` imports the function. Reaction: re-sync `para-shared/`, `/para-triage`, `/para-daily-brief`, `/para-deep-clean` and `/para-upgrade`, and `/para-audit` where installed.

## What changes for you

Nothing you will see: the code the skills share is split into three files so each skill pulls in only what it uses.
