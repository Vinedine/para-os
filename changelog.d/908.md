## Changelog

- In a vault with `.claude/rules/code-repos.md`, run the shared library's `paraos_repos.py convert --vault <root>`; where it reports `changed`, show the table it prints and every `dropped` line, write it with `--write` on the operator's yes, then ask for each `to_fill` entry: the repo's Vault home, and for a repo that builds a website its Site (its `site_hint` is the suggestion) and the vault that site serves: `.claude/rules/code-repos.md`

## Also new

- **The code repos a vault steers are one table.** Each repo now says whether the vault owns it, keeps it for reference or only consults it, where its work lives in the vault, and, for a repo that builds a website, which site and which vault it serves. The upgrade turns the list you have into the table, each repo's description kept word for word, and asks only what it cannot tell from the text.
