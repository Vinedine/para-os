## Safer by default

- **The activity log masks secrets in what people type.** A web address loses everything after its `?`, and an access key or other token becomes `[redacted: token]`. A password typed as plain words is still recorded, so turning prompt recording off stays the way to keep those out.

## What to do

- If a vault records its use: logs already written are not rewritten, so search the files in its `resources/logs/sessions` folder for `?ses=` and for access keys, then sign out of any session and replace any key you find there.
