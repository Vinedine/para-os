## Fixes

- **Your vault's areas line and action-routing sentence can be written its own way.** The `areas/` bullet now fixes only its opening words, so a vault can list its own areas, entity file and cross-cutting area in whatever order reads best. The sentence that says where an action goes fixes only its opening and "Never a root `actions.md`", so a vault can add its own routing clauses. The upgrade stops reporting either as drift, unless a vault drops the root-`actions.md` rule.
