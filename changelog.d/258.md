## Changelog

**`/para-daily-brief review [week|month|since <date>] [<entity>]` looks back over a window, for the vault or one entity.** `brief_scan.py --review` adds a `review` block: Done (each `- [x]` whose `✅` date falls in the window, archived action files included, by entity; a close with no `✅` is counted as undated and never placed in a window), Slipped (open items whose `📅` fell in the window before today), Moved (per lifecycle, entities whose `since` date falls in the window, terminal stages and closed register rows included), Stuck (the overdue lane and the entities with nothing open) and Decisions (dated entries in a `## Development log`, `## Decision log`, `## Log` or `## Decisions` section, or a file so named, outside `sources/`). `week` is the seven days ending today, `month` the thirty. It renders to chat only, never to a file or the dashboard, and one entity's review closes by offering a status update drafted per `para-shared/drafting.md`. Reaction: re-sync `/para-daily-brief`.

## What changes for you

Ask the brief "what did I get done this week?" and it answers with what you closed, which deadlines slipped, which deals or properties changed stage, what is stuck, and the decisions you logged, for the whole vault or one project. For a single project it can also draft the status update a client expects. Items ticked without a completion date are counted, never given one.
