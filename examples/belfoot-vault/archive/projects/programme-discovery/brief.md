# Programme discovery

Map BelFoot's IT landscape and turn the club's modernisation wish list into a programme of workstreams the board can approve, each with an owner, a sequence and a budget envelope.

## Why now

- **No programme yet.** Cashless, ticketing and the fan app were three separate wish-list items with no shared plan, budget or owner.
- **Ticketing end of support.** The current vendor's end-of-life date for our version set the latest start for a replacement.

## Scope

In:

- Interviews with the four directors and the match-day operations team.
- An architecture model of the current landscape, kept in the club's Structurizr workspace.
- A programme plan for the board: workstreams, sequence, owners and budget envelope.

Out:

- Vendor selection for any workstream (each workstream runs its own).
