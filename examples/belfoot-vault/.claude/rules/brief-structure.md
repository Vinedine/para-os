# Briefs

A brief is narrative, shaped by what it documents: no section order is fixed here. A vault that fixes one for a kind of entity does so in a rule file of its own.

- **An idea's brief, and one a declared lifecycle moves, carries a `**Stage:**` line under its title**, which `/para-daily-brief` and `/para-pipeline` read.
- **An archived brief opens on why it was archived**, and is not restructured after.
