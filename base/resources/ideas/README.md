# resources / ideas

Concept-stage ventures or prospects with no committed outcome yet. Use the same `brief.md` shape as a project so they promote cleanly. Promote to `projects/` once committed (deliverable owed, money committed, or a go/no-go on the calendar). Retiring one is always your call and never automatic: an idea that never happened goes to `archive/ideas/`, one where real work ran and then stopped goes to `archive/projects/`.
